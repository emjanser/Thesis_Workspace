# Thesis Workspace

Supervised by Dr. Alex Skillen at the University of Manchester to develop Multi-Fidelity Neural Network (MFNN) models utilizing PyTorch, initially aimed on demonstrating the optimal integration of RANS and LES methods with MFNNs, but later continued improving the model with simpler NACA Aerofoil predictions due to time limitations. Goal of this study was to implement this model into industry and academia, aiming to reduce computation times and improve efficiency in engineering processes.
